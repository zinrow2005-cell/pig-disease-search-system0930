# 豬病圖譜搜尋與症狀判斷系統 V24

## 主要檔案
- `index.html`：系統首頁
- `app.js`：系統功能
- `styles.css`：介面樣式
- `data.js`：疾病與圖片資料
- `taiwan_data.js`：台灣現行資料
- `license_data.js`：台灣動物用藥品許可資料
- `manifest.webmanifest`：PWA
- `sw.js`：離線快取
- `share.html`：LINE / 社群分享專用頁
- `icon-check.html`：部署後圖示檢查頁
